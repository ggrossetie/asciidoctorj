AsciidoctorJ is published to Maven Central.
The artifact information can be found in the tables below.

AsciidoctorJ has two implementations that share the same API (`asciidoctorj-api`): the JRuby implementation (`asciidoctorj`) and the Java implementation (`asciidoctorj-java`).
An application uses one of them, not both.
See xref:index.adoc[] to choose.
